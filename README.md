# Нонфикшен — чтение одной лентой

Кликабельный прототип 375 × 812 по макету Figma `4176:4337`.

Открыть `index.html` через локальный HTTP-сервер или самодостаточный `standalone.html`.
Сборка: `python3 build_standalone.py`.

Пересказ главы включается и выключается в закреплённой верхней панели. При выключении используется текст из макета `4184:20693`.
Панели скрываются при скролле вниз и возвращаются при обратном скролле или тапе по свободному месту. Нижняя шкала регулирует количество вставок. Карусели поддерживают свайп, перетаскивание мышью и стрелки клавиатуры. Плеер сохраняет скрытое состояние панелей при паузе и перемотке.

Выбор подписки, личная заметка и сохранение конспекта остаются в браузере. Плеер демонстрирует управление позицией чтения без звуковой дорожки. Ответ на свободный запрос демонстрационный. Выступление TED открывается во встроенном YouTube-плеере.
