# Нонфикшен — чтение одной лентой

Кликабельный прототип 375 × 812 по макету Figma `4176:4337`.

Открыть `index.html` через локальный HTTP-сервер или самодостаточный `standalone.html`.
Сборка: `python3 build_standalone.py`.

Пересказ главы включается и выключается в закреплённой верхней панели. При выключении используется текст из макета `4184:20693`.
Панели скрываются при скролле вниз и возвращаются при обратном скролле или тапе по свободному месту. Нижняя шкала регулирует количество вставок. Карусели поддерживают свайп, перетаскивание мышью и стрелки клавиатуры. Плеер сохраняет скрытое состояние панелей при паузе и перемотке.

Выбор подписки, личная заметка и состояния сохранения сбрасываются при перезагрузке страницы. Повторный тап по активному варианту или сохранению отменяет выбор. Плеер демонстрирует управление позицией чтения без звуковой дорожки. Ответ на свободный запрос демонстрационный. Выступление TED открывается во встроенном YouTube-плеере.

В режиме оригинала между абзацами добавлены четыре отдельные врезки. Они появляются при уровнях шкалы 20, 40, 65 и 85. На нуле остаётся только авторский текст. Прогресс и перемотка считают только текстовые фрагменты книги; изменение плотности сохраняет положение текущего абзаца.

Ссылка «Дэн Ариели · глава 1» открывает отдельный оригинальный фрагмент с цитатой из карточки. Включение саммери после перехода возвращает к позиции, сохранённой перед тапом. Отрывок также обновлён в Figma (`4222:21371`); предыдущий текст сохранён архивным блоком `4242:3371`.
